SigmawealthSolution production check — 13 October 2026

IMPLEMENTED
Frontend and API accept only NGN 64,000, 98,550, 135,000, 540,000 or 2,160,000 per funding request. Altered amounts are rejected before a provider checkout is created. First-time monthly enrollment uses the selected amount. Bachs fees must be paid by the company, preserving the exact customer amount.
Old payment integrations and local authentication/seed handlers have been removed. Admin routes require a verified Supabase session, confirmed email, allowlist entry and admin role. Investor and support requests require ownership. Financial records cannot be written by browser credentials after the required migration.

Type checking, lint and production frontend/API builds passed. Production API smoke checks returned the expected 401/403/400/410 responses, and the source secret scan passed.
Production dependency audit: zero known advisories. Full audit: 10 build/lint dependency advisories remain (7 high, 3 moderate); this is not a guarantee that the entire system has no vulnerabilities. Details are in npm-audit-all.json.
